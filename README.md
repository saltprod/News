# Моя лента

Telegram Mini App для чтения новостей — один файл, без сборки.

**Демо:** https://saltprod.github.io/News/

## Возможности

- Подборка RSS-источников (BBC, Reuters, TechCrunch, Hacker News и др.) или свой URL
- Полный текст статьи вместо короткого анонса из RSS
- Перевод на русский — бесплатно или через свой OpenAI-ключ
- Компактный список, детали — по клику

## Запуск

Открыть `index.html` в браузере или подключить ссылку как Web App в BotFather.
